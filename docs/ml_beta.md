# Overnight Alpha Lab: 검증 중 베타

공개 화면은 `dashboard.html`입니다. 종목명 또는 6자리 코드로 저장된 ML 예측을 조회하고,
실제 사전 예측의 성과와 검증 진행률을 확인할 수 있습니다. 실시간 시세나 자동매매 서비스는 아닙니다.

## 예측과 추천의 구분

- 목표: 다음 관측 거래일 시가부터 5번째 거래일 종가까지, 수익률이 가정 비용 0.3%를 초과할 확률.
- 모델: 완료된 KIS 수정 일봉의 19개 입력으로 학습한 ExtraTrees 분류기와 별도의 확률 보정기.
- 학습 구간 504개 신호일과 보정 구간 60개 신호일을 분리하며, 경계를 넘는 미래 정답은 제거합니다.
- 기존 901종목 연구 범위를 유지합니다. 입력 이력이 부족하거나 거래가 멈춘 종목은 조회 예측이 없을 수 있습니다.
- 확률 추정은 실제 적중률이나 보장된 신뢰도가 아닙니다. 관찰 목록은 추천 목록과 분리합니다.
- 검증된 추천은 현재 보류합니다. 과거 실험이 좋거나 미래 평가의 일부 표본이 좋다는 이유로 자동 승격하지 않습니다.
- 주문·계좌·자동매매 기능은 없습니다.

## 일별 갱신

GitHub Actions의 **ML Beta**가 평일 한국 시각 16:40에 실행되도록 설정되어 있습니다.
수동 실행은 `Actions → ML Beta → Run workflow`입니다. 스케줄은 지연될 수 있으며,
휴장일에는 마지막으로 관측된 가격 일자가 유지됩니다.

1. 완료된 KIS 가격과 동일 기간의 두 ETF 비교 데이터를 수집합니다.
2. 원본 예측의 미래 결과를 먼저 평가한 뒤, 새로 확인된 정답을 학습합니다.
3. 적시 기록 구간인 경우에만 새 예측을 고정합니다. 개장이 지난 예측을 소급 기록하지 않습니다.
4. 작은 공개 JSON과 HTML, 원본 예측 및 출처 기록을 main에 게시하고 Pages 재배포를 요청합니다.

첫 원격 실행은 전체 과거 이력을 수집하므로 이후 실행보다 오래 걸립니다.
한 종목의 수집이 실패해도 나머지는 수집하고 재시도할 상태를 저장하지만,
불완전한 종목군으로 학습하거나 마지막 정상 공개 화면을 덮어쓰지 않습니다.

## 상태 보관

큰 가격 이력과 모델 바이너리는 Git에 커밋하지 않습니다. 별도의 Actions 캐시에 보관하며,
캐시에는 자격증명·토큰·`.env`를 포함하지 않습니다. 전용 CI 상태에서는 최근 가격 스냅샷과
모델 바이너리 두 개를 유지하고, 과거 원본의 출처 메타데이터는 보존합니다. 로컬 연구 모델은 정리하지 않습니다.
캐시가 사라지면 과거 가격을 다시 수집하고 재학습합니다. 원본 예측과 최소 출처 기록은
별도로 저장하므로 모델 캐시 유무 때문에 기존 예측을 새 예측으로 바꾸지 않습니다.
캐시는 영구 보관소가 아니며 접근 범위에 주의해야 합니다. [GitHub 캐시 문서](https://docs.github.com/en/actions/reference/workflows-and-actions/dependency-caching)

기존 보조 데이터 Pipeline과 ML Beta는 같은 동시 실행 그룹을 사용합니다.
워크플로의 생성 커밋만으로 배포가 시작된다고 가정하지 않고 Pages 빌드를 명시적으로 요청합니다.
[GitHub 워크플로 트리거 문서](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/trigger-a-workflow)

## 해석상의 제한

공개 화면은 모델 추정 확률, 사전 예측의 관측 성공률, 새 목표 검증 진행률을 구분합니다.
서로 다른 날짜의 종목 수를 독립적인 시장 국면 수로 오인하지 않습니다.
관측된 종목 날짜의 합집합 달력, 현재 생존 종목군, 수정 주가, 가정 비용과 체결 조건이라는 제한이 남습니다.
60% 목표와 보수적 통계 검증을 아직 통과하지 않았으며, 이 베타 공개는 성능 인증이 아닙니다.
