## 현재 구현

이 모델은 고정된 v2 점수 공식을 수정하는 방식이 아니라, 가격 데이터를 정답과 연결해 scikit-learn 모델을 실제로 학습합니다.

- 목표: 현재 관측 종가 대비 **향후 5거래일 종가 수익률이 비용 가정 0.3%를 초과할 확률**.
- 수익률 회귀 모델도 별도로 학습해 종가 변화율의 점 추정치를 제공합니다.
- 가격 수익률, 거래량 비율, 변동성, 이동평균 이격도 등 9개 입력을 사용합니다.
- BUY/AVOID 성공 판정을 정답으로 재사용하지 않습니다. HOLD였던 종목도 가격과 미래 관측치가 있으면 학습에 포함됩니다.
- 최초 실험은 종목·일자별 스냅샷을 사용했습니다. 개선 실험은 KIS의 완료된 수정 일봉 시계열로 입력과 정답을 함께 재구성합니다. 두 데이터 경로는 분리 보관합니다.
- 5거래일 구간에 가격 관측 누락이 있거나, 입력이 해당 일자 이후에 처음 수집되었으면 학습에서 제외합니다.

## 학습과 검증

시간순으로 학습 / 확률 보정 / 최종 테스트를 나눕니다. 다음 구간 시작 시점까지 정답이 도착하지 않은 학습 행은 제거합니다.

로지스틱 회귀와 Histogram Gradient Boosting의 비교는 **학습 구간 안의 확장형 시계열 교차 검증**으로만 수행합니다. 마지막 테스트 성적으로 모델 종류나 추천 확률 기준을 바꾸지 않습니다.

별도 중간 구간에서 sigmoid 확률 보정을 학습합니다. 마지막 구간에서는 AUC, Brier score, 클래스 불균형을 고려한 정확도, 기준선, 수익률 오차와 추천 조건 통과 여부를 기록합니다.

새 데이터가 들어오면 모든 사용 가능한 과거 관측으로 다시 데이터셋을 만들고 재학습합니다. 각 실행의 모델·검증 결과·데이터 지문을 별도 폴더에 보관합니다. 재학습 횟수와 실제 성능 개선은 다릅니다.

## 추천 조건과 출력

출력의 `probability_above_cost`는 0~1의 모델 예측 확률이고, `predicted_close_return`은 소수 수익률입니다. 예를 들어 0.01은 +1%입니다. 둘 다 기존 공개 대시보드의 Wilson 신뢰도 점수와 다른 값입니다.

추천 관찰 후보는 검증 기간 20개 신호일 이상, 충분한 선정 표본, 기준선보다 나은 확률 오차와 판별력, 고정 추천 정책의 성과, 일별 수익률의 불확실성 검사 등을 모두 통과해야 합니다. 개별 종목도 예측 확률 60% 이상 및 비용 가정보다 높은 수익률 추정치를 만족해야 합니다. 조건이 부족하면 `RESEARCH_ONLY`와 `ABSTAIN / 추천 보류`를 반환합니다.

현재 보고서에서 기준선이 약한 모델과 비슷하거나 더 좋으면, 예측 숫자를 제공하더라도 검증된 추천으로 취급하지 않습니다.

## 저장과 재학습 연결

모델 파일은 각 모델 디렉터리의 `runs/<실행 ID>/model.joblib`에 저장됩니다. 같은 폴더에 검증 JSON, 최종 테스트 예측 CSV, 리포트가 있습니다. `latest.json`은 해당 디렉터리의 마지막 실행을 가리킵니다. 테스트에 사용한 기간을 마지막 모델 학습에 다시 합치지 않아 보고된 검증 결과와 모델 파일이 대응합니다. 실행 스크립트의 기본 재학습 출력은 `data/models/price_forecaster_challengers`이며 조회·대시보드 모델을 자동 교체하지 않습니다.

catch-up의 자동 ML 학습은 `PRICE_ML_HISTORY_ROOT`에 검증된 완료 일봉 경로가 지정된 경우에만 별도 도전 모델로 실행합니다. 지정하지 않았으면 과거 스냅샷으로 대체 학습하지 않고 명시적으로 건너뜁니다. 별도로 선택된 연구 모델의 공개용 예측을 내보냅니다. GitHub Actions 설정에는 별도 ML 환경과 모델 아티팩트 보관을 추가했지만, 깨끗한 Actions 러너에는 무시된 모델 파일과 일봉 데이터가 자동으로 생기지 않습니다. 원격에서 새 예측을 갱신하려면 해당 입력과 선택 모델의 안전한 복원·갱신 경로가 먼저 필요합니다. 이번 로컬 작업을 배포 완료나 원격 자동 학습 완료로 취급하지 않습니다.

새 학습 실행이 이전 실행보다 좋다는 보장은 없으며, 각 실행의 검증 결과를 비교해야 합니다. 이 첫 버전에는 검증된 챔피언 모델을 자동 교체하는 기능은 없습니다.

기본 `dashboard`는 이미 발행된 공개 JSON을 그대로 사용합니다. 의도치 않게 이전 입력 날짜로 되돌아가지 않도록 공개 예측 저장기도 더 오래된 가격 날짜의 덮어쓰기를 거부합니다. 기본 CLI 조회 모델의 원래 데이터 경로는 수정하지 않으므로 최신 단일 종목 조회에는 위 `--data-root`를 명시합니다. `PRICE_ML_HISTORY_ROOT`가 설정된 catch-up 실행은 그 경로로 `cycle`을 호출합니다. 깨끗한 GitHub 러너의 일봉·모델 복원 문제까지 자동 해결되었다고 주장하지 않습니다.

재무·실적 데이터는 공시 발표 시점을 검증하지 못한 현재 값을 과거 학습에 끼워 넣지 않았습니다. 자세한 해석은 `reports/daily_review/2026-10-21_ohlcv_learning_analysis.md`에 있습니다.

## 학습 구간 내부의 모델 선택과 별도 미래 검증

19개 입력으로 선형 모델, 얕은/중간 깊이의 부스팅, Extra Trees, 고정 평균 앙상블을 비교하는 연구 경로를 추가했습니다. 모델 선택에는 학습 구간 안의 시간 순서 교차 검증만 사용합니다. 미래 정답이 검증 시작일에 걸치는 학습 행을 제거하고, 별도 3~6월 구간으로 확률을 보정합니다. 7월 이후 평가 성적을 보고 모델 종류나 앙상블 가중치를 선택하지 않습니다.

현재 선택 모델은 Extra Trees입니다. 같은 시점·입력·행으로 다시 학습한 얕은 부스팅과 비교한 7~9월 AUC는 0.5533 대 0.5493, 날짜 균형 Brier는 0.249627 대 0.249874였습니다. 오차 차이의 블록 구간은 0을 포함하므로 우위가 확정되지는 않았습니다. 날짜별 AUC 0.5368, 고정 정책 충족 11건·8일로 추천 검증 기준에 미달합니다. 그 11건의 높은 성공률을 전체 모델 신뢰도로 표시하지 않습니다.

수익률 점 추정 외에 보정 구간 오차로 만든 경험적 범위를 제공합니다. 과거 평가 범위 포함률 90.85%는 적중률이나 종목 상승 신뢰도 90.85%를 뜻하지 않습니다. 평균 폭이 34.03%p인 넓은 범위이며 향후 포함률을 보장하지 않습니다.

```bash
# 고정 규약의 학습 전용 모델 선택과 역사 구간 비교 재현
bash scripts/price_model.sh select-model

# 선택된 연구 모델의 이름/코드 조회. 항상 추천 보류입니다.
bash scripts/price_model.sh predict-selected --stock 삼성전자

# 다음 완료 일봉을 수집한 뒤, 유효 기록 창에서 선택 모델의 원본 예측 고정
bash scripts/price_model.sh freeze-selected --data-root data/ml_history/<새_완료일_데이터>

# 충분한 미래 일봉이 도착한 뒤 별도 평가 파일로 채점
.venv-ml/bin/python -m src.evaluator.forward_price_forecast grade \

  --ledger data/predictions/<원본_ml_selected_forward_파일>.csv \
  --output data/predictions/<별도_ml_selected_eval_파일>.csv
```

선택 모델의 원장은 기존 기본 모델의 원장과 분리됩니다. 학습/보정 데이터 식별자·모델 생성 시각·신호일·원래 종가·확률·경험적 범위를 함께 저장하고, 같은 모델/날짜 파일은 덮어쓰지 않습니다. 신호일 16시 이후부터 다음 보수적 개장 시각 전까지만 기록합니다. 장중에 전일 자료로 실행하면 0건으로 건너뛰므로 지난 예측을 미래 검증으로 가장하지 않습니다. 실제 거래소 휴장일 달력이 아니라 보수적 평일 기준을 쓰므로 기록 가능한 휴일 구간을 일부 놓칠 수 있습니다.

이 연구 모델은 기본 공개 모델을 교체하지 않았고 자동 재학습 예약·배포·운영 승격도 하지 않았습니다. 현재 쌓인 역사 구간은 반복해서 살펴본 개발 자료입니다. 다음 단계의 근거는 새 완료 일봉으로 적시에 남긴 예측과 그 이후 실제 결과여야 합니다. 규약과 결과는 `docs/model_experiments/selected_model_protocol_20261021.json`, `reports/daily_review/2026-10-21_selected_price_model.*`, 한국어 해석은 `reports/daily_review/2026-10-21_selected_model_analysis.md`에 있습니다.

## 시장 정보까지 포함한 입력·모델 동시 선택

19개 종목 입력에 관측 후보군의 당일 흐름·상승 종목 비율·거래량·상대 모멘텀 10개를 더한 29개 입력도 비교했습니다. 실제 지수가 아니라 관측 종목군의 대용 지표입니다. 입력 2종류와 모델 구성 5종류, 총 10개 조합을 학습 구간 내부의 순차 검증으로 선택합니다. 평가 구간 성적에 따라 선택 결과를 뒤집지 않습니다.

```bash
# 동일 행·날짜로 비교하고 학습 내부에서 입력/모델을 선택
bash scripts/price_model.sh select-context-model

# 이 실험이 학습 내부에서 선택한 모델 조회. 29개 입력을 강제로 쓰는 명령은 아닙니다.
bash scripts/price_model.sh predict-context --stock 삼성전자
```

실제 결과는 기존 19개 입력의 Extra Trees를 선택했습니다. 29개 입력군에서는 선형 모델이 선택됐지만 학습 순차 검증 Brier가 0.246144로, 19개 Extra Trees의 0.243384보다 나빴습니다. 7~9월 동일 52,002행·62일의 AUC는 19개 0.5533, 29개 0.5364였고, 확률 오차도 29개 입력에서 커졌습니다. 10월 7일 구간의 일부 개선은 표본이 짧고 날짜별 종목 구분력이 약해 교체 근거로 삼지 않았습니다.

두 비교군의 입력 결측 조건을 맞추기 위해 추가 제외된 행은 0건입니다. 기존 후보군, 기본 공개 모델, 기존 선택 모델 포인터, 추천 기준은 유지했습니다. 공통 조회·미래 기록 도구는 허용된 19/29개 입력 스키마를 지원하지만, 원본 예측을 여러 모델의 실적으로 중복 집계하지 않습니다. 이 실험 전용 모델과 큰 비교 CSV는 `data/models/price_forecaster_context_selected/`에 Git 제외로 저장합니다.

한국어 결과는 `reports/daily_review/2026-10-21_context_selection_analysis.md`, 전체 표는 `reports/daily_review/2026-10-21_context_model_selection.md`에 있습니다. 입력이 늘거나 학습을 더 했다는 사실만으로 신뢰도가 상승했다고 표시하지 않습니다.

## 선택적 수익분포 모델

방향 성공 확률 하나만 최대화하는 대신, 5거래일 수익의 네 구간을 동시에 학습하는 별도 모델을 추가했습니다. 구간은 -3% 이하, (-3%, +0.3%], (+0.3%, +3%], +3% 초과입니다. 성공 정의는 기존과 동일하게 +0.3% 초과이며 손실 위험과 높은 상승 가능성을 별도로 볼 수 있습니다.

서로 다른 고정 시드의 Extra Trees 세 개를 학습하고 별도 구간에서 온도를 보정합니다. 학습 자료에서 계산한 구간별 제한 수익·로그 효용 대용치와 각 모델의 분포를 조합합니다. 추천 후보 조건은 상승 확률의 모델 간 최솟값, 큰 하락 확률의 최댓값, 모델 간 불일치, 효용의 최솟값입니다. 최솟값·최댓값은 모델 합의 정도를 나타내는 휴리스틱이지 통계적 신뢰구간이나 보장된 미래 수익이 아닙니다.

학습·확률 보정·정책 선택·외부 평가를 네 구간으로 분리하고 정답 확인일이 다음 구간에 걸치는 행을 제거합니다. 미리 고정한 9개 정책만 5~6월 정책 구간에서 비교합니다. 통과에는 100건·20일 이상, 날짜 균형 성공률 65% 이상, 성공률 블록 하한 55% 이상, 모든 날짜 포함 수익 대용치의 하한 양수가 필요합니다. 정책 9개·경계 2개에 다중 비교 보정을 적용합니다. 통과한 정책이 없으면 추천을 강제로 만들지 않습니다.

```bash
# 사전 규약의 분포 학습·별도 정책 선택·같은 날짜 기준선 비교
bash scripts/price_model.sh distribution-model train

# 종목 조회. 위험·불일치·보류 여부를 함께 표시하며 항상 연구용입니다.
bash scripts/price_model.sh distribution-model predict --stock 삼성전자

# 새 완료 일봉이 준비된 유효 시각에만 원본 미래 예측 고정
bash scripts/price_model.sh distribution-model freeze \
  --data-root data/ml_history/<새_완료일_데이터>

# 후속 완료 일봉으로 채점. 원본이 아닌 별도 경로를 사용합니다.
.venv-ml/bin/python -m src.evaluator.forward_price_forecast grade \
  --data-root data/ml_history/<후속_완료일_데이터> \
  --ledger data/predictions/<ml_distribution_forward_원본>.csv \
  --output data/predictions/<ml_distribution_eval_별도출력>.csv
```

같은 날짜 전체 대상의 결과가 확인된 날짜만 과거 순위 평가에 포함합니다. 결과가 없는 일부 종목만 빼고 순위를 다시 만드는 사후 선택은 하지 않습니다. 전체 날짜 제외 역시 평가 편향의 한계가 있어 별도 보고합니다. 진단용 Top20은 실제 추천 목록이 아니며, 동일 시점 이진 모델·모멘텀·고정 난수 100회 평균과 비교합니다. 모델은 별도 스키마로 저장하고 공개 기본 모델을 교체하지 않습니다.

선택적 예측의 참고 연구는 [Deep Gamblers](https://arxiv.org/abs/1907.00208), 분포 변화에 따른 이론적 조건 검토는 [Non-Exchangeable Conformal Risk Control](https://arxiv.org/abs/2310.01262)입니다. 이번 코드는 두 논문의 알고리즘 재현이나 정리 적용이 아니며, 새로운 알고리즘 발명이나 컨포멀 보장을 주장하지 않습니다. 시계열 블록 구간은 역사 구간의 근사 진단이고 미래 적중률 보장이 아닙니다.

고신뢰도 기준 통과와 운영 승격은 별개입니다. 이 경로는 항상 연구용·추천 보류이며, 실제 미래 평가 전에는 검증된 고신뢰도 추천으로 발행하지 않습니다. 기존 후보군·기본 대시보드·운영 스코어·다른 모델의 원장은 유지합니다. 모델 파일과 큰 연구 CSV는 `data/models/price_distribution_selector/`에 Git 제외로 저장합니다. 자동 거래·스케줄·원격 배포는 추가하지 않았습니다.

실제 학습에서는 추천 정책이 하나도 통과하지 못했습니다. 7~9월 동일한 완전 날짜 47일의 확률 오차는 대조군보다 낮았지만 차이의 블록 구간은 0을 포함했습니다. 무조건 Top20을 고른 진단의 평균 수익도 극단값에 민감했습니다. 고신뢰도 모델을 확보했다고 표시하지 않았습니다. 결과와 민감도 분석은 `reports/daily_review/2026-10-21_distributional_selector_analysis.md`, 전체 자동 산출물은 `reports/daily_review/2026-10-21_distributional_selector.*`에 있습니다.

## AI 기반 신호 수식 탐색

사람이 고정 지표만 만드는 방식에서 확장해, 유전 프로그래밍으로 신호 수식을 생성하는 연구 엔진을 추가했습니다. [gplearn 공식 문서](https://gplearn.readthedocs.io/en/stable/reference.html)의 `SymbolicTransformer`를 사용합니다. 생성 후보가 있다는 사실만으로 새로운 과학적 알고리즘이나 고신뢰도 모델을 발견했다고 주장하지 않습니다.

입력은 기존 OHLCV 19개와 그날 입력이 유효한 전체 후보의 백분위 순위입니다. 순위는 미래 결과를 보기 전에 계산합니다. 수식의 재료는 이 19개 순위와 고정된 안전 산술 연산뿐이며 Python 문자열을 `eval`/`exec`하지 않습니다.

탐색 예산은 128개체·6세대입니다. 과거 학습 자료의 앞부분에서 수식을 진화시키고, 그 뒤 학습 기간의 세 구간에서 날짜별 상대 신호가 유지되는지 검사합니다. 단순 입력의 복사, 상수, 지나치게 복잡한 수식은 제외합니다. 계산용 표본은 날짜별 고정 난수로 최대 64행을 쓰지만, 최종 모델 학습·종목 조회·전체 후보군은 축소하지 않습니다.

생존 수식을 추가한 모델과 추가하지 않은 동일한 선형 모델을 비교합니다. 별도의 Extra Trees 대조군·모멘텀·무작위 기준선도 유지합니다. 수식 탐색의 상대 수익 순위 목표와 최종 추천의 절대 성공 목표는 다릅니다. 최종 예측 확률과 채점 기준은 여전히 실제 5거래일 수익이 +0.3%를 넘는지입니다.

수식 생성·생존 검사·모델 학습은 모두 학습 구간 내부입니다. 확률 보정, 추천 정책 선택, 이후 과거 평가를 별도 날짜로 분리하고 경계를 넘는 정답을 제거합니다. 정책 문턱 55/60/65/70%는 정책 구간에서만 선택하며, 표본·성공률·하한·수익 조건을 통과한 문턱이 없으면 추천을 만들지 않습니다. 수식이 하나도 살아남지 않으면 0개로 보고하고 성능 개선을 주장하지 않습니다.

```bash
# 이미 생성한 격리 환경을 재현할 때만 필요
.venv-ml/bin/python -m venv .venv-discovery
.venv-discovery/bin/python -m pip install -r requirements-discovery.txt

# 수식 생성·생존 검사·모델/정책 학습·비교
bash scripts/price_model.sh discover-model train

# 종목명 또는 코드 조회, 항상 연구용/추천 보류
bash scripts/price_model.sh discover-model predict --stock 삼성전자

# 완료 일봉이 준비된 유효 시각에 원본 미래 예측 고정
bash scripts/price_model.sh discover-model freeze \
  --data-root data/ml_history/<새_완료일_데이터>
```

원장은 `ml_discovery_forward_`라는 별도 이름이며 원본을 덮어쓰지 않습니다. 5거래일 뒤 기존 `forward_price_forecast grade` 도구로 별도 평가 CSV를 만들 수 있습니다. 학습 데이터 식별자에는 같은 날 종목 구성에 영향을 받는 순위 입력도 포함합니다. 다른 모델의 미래 실적과 합치지 않습니다.

gplearn 0.4.3이 요구하는 scikit-learn 때문에 `.venv-discovery`를 별도로 사용합니다. 기존 `.venv-ml`과 이전 모델 파일은 업그레이드하거나 덮어쓰지 않습니다. 연구 환경은 `requirements-discovery.txt`로 고정하며 모델은 Git에서 제외한 `data/models/price_formula_discovery/`에 저장합니다. 운영·대시보드 기본 모델 교체·예약 실행·원격 배포는 하지 않습니다.

생성 수식의 상대 상관과 생존 검사는 탐색용 기준이며 미래 적중률 보장이 아닙니다. 현재 종목군·사후 수정주가·전체 날짜 제외·반복해서 살펴본 역사 구간의 한계가 남습니다. 상세 규약은 `docs/model_experiments/formula_discovery_protocol_20261021.json`, 자동 산출물은 `reports/daily_review/2026-10-21_formula_discovery.*`입니다.

### 잔차 기반 후속 탐색이 현재 기본값

첫 탐색에서 생존한 3개 수식은 기존 순위 입력의 단순한 합이었습니다. 선형 모델의 입력에 선형 합을 더하는 것은 새로운 표현력을 주지 않으므로, 이를 새로운 예측 알고리즘 발견으로 해석하지 않았습니다. 첫 모델·규약·결과는 위 경로에 보존합니다.

현재 `discover-model` 기본값은 잔차 기반 후속 실험입니다. 학습 자료 앞부분에서 표준화/Ridge 기준 모델을 세 번의 순차 검증으로 학습합니다. 각 행의 기준 예측은 그 행보다 이전에 정답이 확인된 자료로만 만듭니다. 유전 프로그래밍은 이 표본 외 예측의 오차를 설명하는 수식을 찾습니다. 후속 학습 구간의 잔차는 앞부분 전체로만 학습한 고정 기준 모델에서 계산합니다.

최종 분류기 입력과 같은 기존 38개 값으로 재현되는 수식도 제외합니다. 발견 구간에서 기존 입력의 선형 조합으로 회귀한 잔차 비율이 최소 5%여야 합니다. 이 조건과 뒤의 세 학습 구간 생존 검사를 모두 통과해야 최종 입력에 추가합니다. 정책 구간·외부 평가 구간을 수식 생성에 사용하지 않으며, 추천 기준을 낮추지 않습니다.

후속 규약은 `docs/model_experiments/formula_residual_discovery_protocol_20261021.json`, 모델은 `data/models/price_formula_residual_discovery/`, 결과는 `reports/daily_review/2026-10-21_formula_residual_discovery.*`입니다. 위의 `discover-model train/predict/freeze` 명령은 이 후속 모델을 사용합니다. 첫 실험과 마찬가지로 역사 구간을 반복해서 본 개발 실험이며 독립적인 새 검증이 아닙니다. 생존 수식이 0개여도 임의로 조건을 완화하거나 성공한 것처럼 표시하지 않습니다.

실제 후속 탐색에서는 비선형 후보 2개가 생존했지만, 동일 47일 외부 과거 평가에서 기존 Extra Trees를 이기지 못했고 추천 정책도 전부 탈락했습니다. 후보 수식 생성 성공을 고신뢰도 모델 완성으로 바꾸어 표시하지 않았습니다. 두 실험의 비교와 실제 수식·실패 원인은 `reports/daily_review/2026-10-21_formula_discovery_analysis.md`에 있습니다.

## 사례 기억과 지연 정답 기반 적응형 결합

검색 기반 예측과 할인된 과거 오차를 사용하는 전문가 결합을 참고한 연구 모델을 추가했습니다. 고정된 Extra Trees, 이미 정답이 알려진 유사 과거 사례, 최근 날짜별 실제 상승 비율을 세 전문가로 둡니다. 그날의 결과가 아니라 과거에 미리 만든 날짜 묶음의 정답이 전부 확인된 뒤에만 결합 비중을 갱신합니다.

과거 사례는 최대 252개 신호일에서 날짜당 32개 입력을 고정 난수로 표본화하고, 128개 가까운 사례를 검색합니다. 표본 키는 결과 유무를 보기 전에 전체 입력에서 정합니다. 날짜당 표본은 계산량 제한이며 최종 후보군은 줄이지 않습니다. 같은 날짜의 여러 종목은 먼저 날짜 단위 투표로 합치고 최근 사례에 더 큰 비중을 줍니다. 최소 20개 서로 다른 원천 날짜와 거리 조건이 충족되지 않으면 사례 확률을 최근 비율로 되돌립니다.

다음 원칙을 지킵니다.

- 기억에 들어가는 정답 확인일은 예측일보다 엄격히 앞서야 합니다.
- 날짜 묶음의 일부 결과만 도착하면 전문가 비중을 갱신하지 않습니다.
- 날짜 묶음마다 한 번만, 당시 저장한 원본 전문가 예측의 평균 Brier로 갱신합니다.
- 사례 지원과 모델 간 동의는 휴리스틱이며 적중률 보장이나 독립 표본 수가 아닙니다.
- 추천 문턱은 별도 정책 기간에서만 고르고, 이후 과거 평가 성적을 보고 다시 고르지 않습니다.

```bash
# 고정 규약으로 고정 모델 학습 후 지연 정답의 시간 순서 재현
bash scripts/price_model.sh memory-model train

# 최신 연구 스냅샷의 종목명/코드 조회. 실시간 API 조회가 아닙니다.
bash scripts/price_model.sh memory-model predict --stock 삼성전자

# 그 스냅샷 신호일의 유효 시각에만 원본 미래 예측 고정
bash scripts/price_model.sh memory-model freeze
```

새 일봉 경로를 사용하려면 `memory-model train --data-root <새_완료_일봉_경로>`로 새 연구 실행을 만들되, 규약의 `labels_as_of`도 실제 완료일에 맞춰 별도 규약으로 기록해야 합니다. 기존 실행의 과거 예측은 수정하지 않습니다. 이는 수동 연구 재실행이며 백그라운드 상시 학습이나 예약 실행을 설치한 것은 아닙니다. 별도 실제 원장 `ml_memory_forward_*.csv`는 적시 기록만 가능하고 기존 `forward_price_forecast grade` 도구로 별도 채점합니다.

5~10월 역사 재현에서는 113개 신호일·94,639개 예측을 만들고 86개 완료 날짜 묶음으로 전문가 비중을 갱신했습니다. 이 94,639건을 실제 사전 기록된 미래 검증 실적으로 세지 않습니다. 7~9월 동일 47일의 Brier는 고정 모델 0.249859, 사례 기억 0.244716, 최근 비율 0.246657, 단순 평균 0.241574, 적응형 0.243872였습니다. 적응형이 단순 평균보다 우월하지 않았고 추천 정책도 모두 탈락했습니다.

공식 연구의 참고는 [TabR](https://arxiv.org/abs/2307.14338), [Discounted Expert Advice](https://arxiv.org/abs/1005.1918), 불확실성의 시간 변화 검토는 [AgACI](https://proceedings.mlr.press/v162/zaffran22a.html)입니다. 해당 논문들의 재현이나 이론 보장을 이번 할인·지연·지지 조건의 조합에 적용했다고 주장하지 않습니다. 추천은 계속 보류하며 공개 기본 모델·기존 실적·원장은 유지합니다.

규약은 `docs/model_experiments/adaptive_memory_protocol_20261021.json`, 자동 보고서는 `reports/daily_review/2026-10-21_adaptive_memory.*`, 한국어 해석은 `reports/daily_review/2026-10-21_adaptive_memory_analysis.md`입니다. 대형 실행 산출물은 `data/models/price_memory_router/`에 Git 제외로 저장합니다.

## 다음 날 진입 기준 학습과 실제 미래 검증

기존 모델은 장 마감 가격을 입력으로 쓰면서 그 종가부터의 수익률을 예측했습니다. 이 연구용 목표는 실제로 다음 날 매수하는 결과와 다릅니다. 새 모델은 **다음 관측 거래일 시가부터 다섯 번째 관측 거래일 종가까지**, 가정 비용 0.3%를 넘는지를 학습합니다. 실제 주문 기능은 없고 체결·호가 대기·충격 비용을 보장하지 않습니다. 기존 모델의 정답이나 성공률을 소급 변경하지 않습니다.

진입/청산 날 거래가 없거나 중간 거래일의 가격이 누락되면 미평가로 남깁니다. 보유 중 하루 가격 변동이 30.5%를 넘는 경우에는 기업행사 등 별도 확인이 필요하다고 표시합니다. 이것은 오류 확정이나 거래소 규정의 일반화가 아니며, 여러 날에 걸친 큰 수익을 잘라내는 규칙도 아닙니다. 원본의 구조적 오류는 조용히 제거하지 않고 학습을 중단합니다.

후보는 미래 정답을 보기 전에 전체 입력으로 정하고 순위를 매깁니다. 선택한 종목의 결과가 미확인이어도 다른 종목으로 대체하지 않습니다. 미확인 종목이 있으면 전체 정책 수익을 확정하지 않습니다. 후보군 생성이나 공개 대시보드의 기존 지표는 바꾸지 않았습니다.

```bash
# 정답 기준만 바꾼 동일 알고리즘 대조 실험. 별도 과거 연구 모델에 저장
bash scripts/price_model.sh next-open-model train

# 최근 정답으로 실제 재학습: 504개 신호일 학습, 이후 60개 신호일 확률 보정
# 각 구간 경계에서 아직 미래인 정답은 제외. 이 모델은 미래 검증 전용
bash scripts/price_model.sh next-open-model fit-current \
  --data-root data/ml_history/kis_updated_20261020 --as-of 2026-10-20

# 오늘 확정 일봉으로 종목 조회. 숫자는 미검증 연구 확률이지 신뢰도 보장이 아님
bash scripts/price_model.sh next-open-model predict \
  --data-root data/ml_history/kis_updated_20261021 --stock 삼성전자

# 오늘 마감 후부터 다음 보수적 영업일 오전 9시 전까지 원본 예측 고정
bash scripts/price_model.sh next-open-model freeze \
  --data-root data/ml_history/kis_updated_20261021

# 이후 가격이 도착하면 별도 평가 파일에 채점. 기존 원장에는 쓰지 않음
bash scripts/price_model.sh next-open-model grade \
  --data-root data/ml_history/<새_확정_일봉> --as-of <완료일> \
  --ledger data/predictions/ml_next_open_forward_<신호일>_<모델키>.csv \
  --output data/predictions/ml_next_open_forward_eval_<평가일>.csv
```

새 명령의 일반 조회 기본값은 최근 학습 모델 `data/models/price_next_open_current/`입니다. `train` 대조 실험만 `data/models/price_next_open/`을 사용합니다. 두 모델은 서로와 기존 운영 모델을 덮어쓰지 않습니다. 모델 파일은 Git에서 제외하며, 새 원장은 기존 종가 기준 채점기에 넣지 않고 반드시 `next-open-model grade`로 평가합니다.

현재 추천은 **보류**입니다. 최근 학습 모델의 보정 자료는 시험 성적이 아니며, 과거 개발 실험의 개선도 독립적인 미래 검증을 대신하지 않습니다. 실제로 한 재학습과 아직 확보하지 못한 미래 검증을 구분합니다. 이 명령은 백그라운드 예약 학습이나 자동 배포를 설치하지 않습니다.

### 새 정답이 생겼을 때만 학습하는 피드백 경로

```bash
bash scripts/price_model.sh learn-next-open \
  --data-root data/ml_history/kis_updated_20261021
```

새 경로는 먼저 원본 사전 예측의 파일 지문·모델 식별자·기록 시각을 검증하고, 별도 파일에 평가합니다. 확정된 정답으로 만드는 504일 학습/60일 보정 자료의 지문이 이전 모델과 같으면 **재학습하지 않습니다**. 새 자료라면 기존 실행을 남기고 새 모델을 학습합니다. 새 모델 학습 완료 시각보다 먼저 예측을 발행하지 않으며, 장 시작 뒤 어제 날짜의 새 원장을 소급 생성하지 않습니다. 같은 날 재학습하더라도 원본 예측이 이미 있으면 첫 원본을 유지합니다.

정답이 당일 종가에 확정됐고 충분한 마감 버퍼 뒤 학습을 끝냈다면, 그 당일 마감 신호로 다음 날을 예측하는 것은 가능합니다. 학습 정답 확인일이 신호일보다 미래이면 차단합니다. 날짜만 같다고 차단하거나 미래 정보를 허용하지 않습니다.

공개 화면은 같은 날 기록된 원본 확률을 우선 표시합니다. 재학습한 새 확률로 어제 원본을 바꾸지 않습니다. 화면의 학습 정답 기준일은 최신 학습 상태이며, 실제 미래 평가 건수는 **같은 다음 시가 목표를 쓰는 학습 시스템의 사전 발행 기록**입니다. 버전이 다른 모델을 한 고정 모델의 실적으로 표시하지 않습니다. 같은 신호일에 여러 원장이 있어도 가장 먼저 적시에 발행한 묶음 하나만 정답을 보기 전에 고르며, 이후 원장은 삭제하지 않습니다. 다른 종가 목표의 과거 실적은 합치지 않습니다.

현재 모델은 확률만 학습하므로 예상 수익률을 0%로 만들지 않고 **미제공**으로 표시합니다. 조회 가능하다는 사실, 추정 확률이 높다는 사실, 검증된 추천이 가능하다는 사실을 분리합니다. 이 경로는 추천을 자동 승인하지 않습니다. 자동 예약과 GitHub 배포도 별도 작업이며 이번에 설치하지 않았습니다.

## 자연모방 신경회로와 종목 간 정보 교환 연구

두 가지 가설을 실제 모델로 구현했습니다. 기존 공개 추천 모델을 교체하거나 고신뢰도라고 승인한 것은 아닙니다.

첫 가설은 소형 생물의 신경회로에서 영감을 받은 NCP/CfC가 시간 흐름을 더 잘 학습하는지입니다. 공식 `ncps` 구현을 사용합니다. 이 구조의 원천 연구는 선충 신경계에서 영감을 받았으며, 실제 벌·개미·곤충의 신경계를 그대로 복제했다는 주장은 아닙니다. 같은 19개 입력의 과거 20거래일을 사용하고, 마지막 하루만 보는 MLP, 일반 GRU, dense CfC, sparse NCP CfC, 동일 표본 Extra Trees를 비교합니다.

두 번째 가설은 개별 모델이 다른 종목의 관측 신호를 전달받으면 도움이 되는지입니다. 학습 구간 두 절반에서 같은 부호로 재현된 하루 지연 관계만 남기고, 종목별 최대 4개 연결을 만듭니다. 시장 공통 움직임은 먼저 빼며, 양수·음수 연결을 모두 허용합니다. 연결 수와 가중치는 그대로 두고 상대 종목만 바꾼 무작위 연결 대조군과, 같은 정보를 받는 일반 GRU도 비교합니다. 이는 부호 있는 정보 교환의 연구 가설이며, 인과관계 발견이나 개미 군집 최적화 알고리즘의 재현은 아닙니다.

```bash
# 기존 ML/수식 탐색 환경과 분리
.venv-ml/bin/python -m venv .venv-neuro
.venv-neuro/bin/python -m pip install -r requirements-neuro.txt

# 신경회로 구조 비교 및 그 부모 모델에 대한 정보 교환 비교
bash scripts/price_model.sh neural-model train
bash scripts/price_model.sh swarm-model train

# 종목명 또는 코드의 연구용 예측
bash scripts/price_model.sh neural-model predict --stock 삼성전자 --data-root <새_완료_일봉>
bash scripts/price_model.sh swarm-model predict --stock 005930 --data-root <새_완료_일봉>

# 실제 마감 후부터 다음 개장 전까지 원본과 모든 대조군 확률을 함께 기록
bash scripts/price_model.sh neural-model freeze --data-root <새_완료_일봉>
bash scripts/price_model.sh swarm-model freeze --data-root <새_완료_일봉>

# 미래 가격이 도착하면 반드시 별도 평가 파일에 원본 확률로 채점
bash scripts/price_model.sh neural-model grade --data-root <새_완료_일봉> \
  --ledger <ml_neural_circuit_forward_원본.csv> --output <별도_평가.csv>
bash scripts/price_model.sh swarm-model grade --data-root <새_완료_일봉> \
  --ledger <ml_swarm_circuit_forward_원본.csv> --output <별도_평가.csv>
```

신경망 크기·8회 반복 학습·두 난수 시드의 단순 평균·정규화·확률 보정 구간·추천 문턱은 규약에 고정합니다. 탐색용 학습 계산량을 제한하기 위해 날짜당 입력 후보 64개를 정답 확인 전에 뽑아 모든 대조군에 동일하게 사용합니다. 이는 **학습 계산 예산**이며 최종 예측 후보군을 64개로 줄이는 것이 아닙니다. 평가·현재 조회·미래 원장은 유효한 전체 후보를 사용합니다. 이 탐색이 전체 데이터로 대규모 학습했을 때의 한계를 입증하는 것도 아닙니다.

시계열 이력이 없다고 종목을 삭제하거나 다른 종목의 이력을 이어 붙이지 않습니다. 명시적으로 센 마지막 하루 모델의 원시 확률로 대체합니다. 전달받을 종목이 없을 때는 관측 커버리지 0으로 표시합니다. 선택 종목의 미래 결과가 없으면 다른 종목으로 대체하지 않습니다.

원본 CSV와 함께 `.manifest.json`을 배타적으로 생성해 모델 식별자, 주 모델, 모든 대조군 목록과 파일 지문을 봉인합니다. 평가 시 파일 변경이나 사후 주 모델 변경을 차단합니다. 기존 전체 학습 Extra Trees가 있으면 그 확률과 식별자도 실제 기록 시각에 함께 저장합니다. 과거의 작은 표본 대조군만 이겼다는 이유로 기존 모델을 이겼다고 주장하지 않습니다. 서로 다른 실험의 원장은 합쳐서 독립 표본 수를 부풀리지 않습니다.

실제 시각은 계산을 시작할 때뿐 아니라 예측을 계산한 뒤에도 다시 확인합니다. 다음 개장까지 최소 1분의 저장 여유가 없으면 새 원장을 만들지 않습니다. 계산 도중 개장을 넘긴 예측을 시작 시각으로 소급 기록하지 않습니다.

큰 파일은 `data/models/price_neural_circuit/`, `data/models/price_swarm_circuit/`에 Git 제외로 저장합니다. 전달 모델은 부모 실행에 대한 고정 참조를 보관하므로 부모의 최신 포인터가 바뀌어도 기존 실행을 로드합니다. 실행 폴더와 부모 실행은 함께 보존해야 합니다. 공개 화면에 실험 디버그 정보를 추가하지 않고 `docs/diagnostics.html`에만 비교 표를 표시합니다. 이 페이지도 접근 제어된 비공개 저장소가 아니라 별도의 진단 화면입니다.

규약은 `neural_circuit_protocol_20261022.json`과 `swarm_circuit_protocol_20261022.json`입니다. 실제 결과와 제한은 `2026-10-22_nature_model_analysis.md`에 기록합니다. 이 모델들은 신뢰도 향상을 아직 입증하지 못했으며, 자동 예약·운영 승격·자동 주문을 하지 않습니다.

## 추천 판단 모델: 예측과 추천 보류의 분리

`selective-model`은 기존 다음 시가 기준 모델을 덮어쓰지 않는 별도 연구 경로입니다. 2025년 7월부터 매월 시작 전에 과거 504개 신호일을 학습하고 60일로 보정한 Extra Trees를 만들어, 그 다음 달 전체 후보의 예측을 기록합니다. 각 예측의 모델 기준일·마지막 학습 정답일을 보관합니다. 이 과거 재현은 실제 당시 발행된 원본이 아니므로 미래 검증 성적으로 표시하지 않습니다.

추천 판단 모델은 이 시간 외 예측으로만 학습합니다. 예측 확률, 같은 포리스트 내부 네 그룹의 분산, 과거 학습 분포와 입력의 거리, 현재 관측 가능한 시장·종목 정보, 그날 이전에 확인된 최근 예측 오차를 사용합니다. 포리스트 내부 분산을 독립적인 여러 모델의 동의나 신뢰도로 오해하지 않습니다. 최근 오차는 관측 달력상 이미 결과 시점이 지난 후보 가운데 실제 정답을 확인한 것만 사용하고, 미확인 비율도 입력으로 남깁니다.

두 번째 단계는 과거 126개 신호일로 고정된 얕은 HGB를 학습하고 별도 30일로 확률을 보정합니다. 학습 정답이 보정 구간을 침범하지 않도록 제거하며, 월별 평가 전에 두 단계 모두 학습을 끝낸 것으로 재현합니다. 확률만으로 같은 단계를 학습하는 로지스틱 보정 대조군을 함께 두어, 새 판단 모델이 단순한 확률 보정보다 나은지 비교합니다. 정답은 BUY 기준 비용 초과 상승 여부로 동일하며 AVOID 성적을 섞지 않습니다.

주 비교는 모든 후보 중 매일 같은 5개를 고르는 연구 순위 비교입니다. 이는 매일 5개를 매수하라는 뜻이 아닙니다. 별도의 60% 문턱 정책에서는 판단 모델이 입력만으로 정한 그날 선택 수를 모든 대조군에 똑같이 적용합니다. 미확인 종목을 뺀 뒤 다시 고르거나 결과가 없는 종목을 수익 0으로 바꾸지 않습니다. 주 비교 두 개의 날짜 블록 재표집 구간에 다중 비교 보정을 적용합니다. 선택 결과가 빠진 날짜는 달력에서 압축 삭제하지 않으며, 완전한 기간 성과의 하한은 제공하지 않습니다.

```bash
bash scripts/price_model.sh selective-model train
bash scripts/price_model.sh selective-model predict --stock 삼성전자 --data-root <완료_일봉>
bash scripts/price_model.sh selective-model freeze --data-root <완료_일봉>
bash scripts/price_model.sh selective-model grade --data-root <새_완료_일봉> \
  --ledger <ml_selective_forward_원본.csv> --output <별도_평가.csv>
```

실제 원본 발행은 완료 일봉 이후 다음 개장 1분 전까지만 가능하며, 장중에 어제 예측을 소급 발행하지 않습니다. 원본에 세 방식의 확률과 선택 여부를 함께 봉인하고, 평가 시 고정 선택 규칙과 원본 지문을 검증합니다. 월별 기본 예측기는 해당 달에만 사용하므로 달이 바뀌면 새 학습이 필요합니다. 파일은 `data/models/price_selective_gate/`에 Git 제외로 보존하고, 기존 21일·22일 미래 예측이나 공개 추천 상태를 대체하지 않습니다.

규약은 `selective_price_protocol_20261023.json`, 결과는 `2026-10-23_selective_recommendation.md/.json`입니다. 비교 표는 내부 진단 페이지에만 표시합니다. 두 번째 모델이 예측 정보를 새로 만들어 낸다고 가정하지 않으며, 개선은 실험으로 확인해야 합니다. 접근의 일반적 배경은 [선택적 예측 연구](https://proceedings.mlr.press/v97/geifman19a.html)이며, 이 구현이 SelectiveNet 구조를 재현한 것은 아닙니다.
