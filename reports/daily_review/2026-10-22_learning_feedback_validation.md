# 실제 정답 기반 학습 연결 및 검증

## 이번에 실제로 한 일

기존 Desktop 저장소에서 다음 시가 기준 모델의 학습 피드백과 대시보드 연결을 구현했다. 고신뢰도 모델 완성이나 성능 향상을 확정한 보고서는 아니다.

- 10월 21일까지 새로 정답이 확정된 829개 행을 추가로 반영했다. 고정 504일 학습 / 60일 확률 보정 창이 이동하므로 전체 학습 행수가 829만큼 증가하는 방식은 아니다.
- 분류기 학습: 2024-06-11~2026-07-07, 504개 신호일, 425,660행. 마지막 정답 확인일 7월 14일.
- 확률 보정: 2026-07-15~2026-10-14, 60개 신호일, 49,675행. 마지막 정답 확인일 10월 21일.
- 실제 새 모델 생성 시각: 2026-10-22 09:31:03 KST.
- 같은 자료를 반복 실행한 결과는 `no_new_fit_rows_model_preserved`, 추가 정답 0건이었다. 모델 식별자와 생성 시각이 유지됐다.
- 새 모델 자료 지문: `d3e4c3ccce5adabe7e22fa888cb416ecde0019249424409e4da3632a1fa94818`.

자료가 추가될 때만 다시 학습한다는 것은 원본 학습/보정 행과 정답·입력값을 모두 지문으로 비교한다는 뜻이다. 같은 정답 날짜라도 공급자 자료가 정정돼 학습 행이 바뀌면 별도 정정 재학습 상태로 보고한다. 모델 자신의 예측값을 정답으로 삼지 않는다.

## 실제 미래 예측은 별도

어제 2026-10-21 16:12:13 KST에 기록한 833개 원본 예측은 그대로 보존했다. 해당 예측의 진입일은 오늘 이후 관측되는 첫 거래일이며, 최종 평가에는 다섯 번째 거래일 종가가 필요하다. 현재 완료 일봉은 10월 21일까지이므로 833개 모두 결과 대기다. 이번에 학습에 반영한 829개 정답은 이 833개 예측의 결과가 아니다.

원본 파일:
`data/predictions/ml_next_open_forward_20261021_98ed5285bba06867.csv`

원본 SHA256:
`f675e446bdf635207966439ec7b1a9be626600086d8362fd351272be62ac52c6`

새 학습 실행은 장 시작 후였으므로 어제 날짜의 새 원본을 만들지 않았다. 같은 날짜에 여러 모델 원장이 있어도 가장 먼저 적시에 기록한 날짜 묶음을 정답 확인 전에 선택한다. 원본 파일은 삭제하거나 바꾸지 않는다. 파일 지문 등록부로 이후 변경도 차단한다.

## 대시보드 연결

- 가격 기준일 10월 21일, 종목 조회 833개, 학습 정답 기준일 10월 21일을 표시한다.
- 조회 확률은 장 시작 전 기록한 원본을 우선 표시한다. 새 모델로 다시 학습한 확률이 어제 예측을 소급 변경하지 않음을 전체 833개 종목에서 비교 확인했다.
- 실제 미래 평가 완료 0건, 결과 대기 833건이며 추천은 보류다. 결과를 확인할 수 없는 상태는 미래 결과 대기와 별도로 센다.
- 미래 평가 건수는 동일한 다음 시가 정답을 사용하는 학습 시스템의 사전 예측 기록이다. 서로 다른 버전을 한 고정 모델의 성적이라고 표시하지 않는다. 기존 종가 기준 모델이나 DART 평가를 섞지 않는다.
- 새 모델이 학습하지 않는 수익률 점추정은 0%로 꾸미지 않고 미제공으로 표시한다.
- 이름/종목코드 조회, 관찰 목록, 추천 보류, 오래된 페이지의 추천 차단, 1440/390/320px 화면을 실제 Chrome에서 검사했다. 가로 넘침과 JavaScript 오류는 없었다.

## 검증과 현재 한계

전체 단위 테스트 123개가 격리 연구 환경에서 통과했다. 기본 ML 환경은 선택적 수식 탐색 통합 테스트 1개를 제외하고 통과했다. 수정한 Python 파일 컴파일, 셸 구문 검사, `git diff --check`도 실행했다.

기존 레거시 CSV를 읽는 대시보드 생성 과정에서 pandas 혼합 자료형 경고가 발생했지만 HTML 생성은 성공했다. 이번에 레거시 지표 계산은 바꾸지 않았다.

이 결과는 학습 및 검증 흐름이 연결됐다는 증거이지, 모델의 실제 미래 적중률이 올랐다는 증거가 아니다. 아직 새 모델의 독립적인 미래 성적은 없다. 추천 기준을 낮추거나 검증 전 모델을 승인하지 않았다. 기존 모델 실행도 보존했다.

변경 사항은 로컬 작업 상태다. GitHub 커밋/푸시/Pages 배포, 백그라운드 예약 실행, 자동 주문은 이번 작업에 포함하지 않았다. 다음 확정 일봉을 준비한 뒤 `learn-next-open`을 실행하면 새로 확정된 정답만 학습하고 원본 평가 상태를 갱신한다.
