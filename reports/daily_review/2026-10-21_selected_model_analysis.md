# 학습 모델 선택 및 불확실성 검증

## 이번 구현

- 901종목의 검증된 완료 OHLCV에서 19개 입력을 사용합니다. 후보군은 줄이지 않았습니다.
- 고정한 다섯 모델 후보를 학습 구간 내부의 세 번의 순차 검증으로만 비교합니다.
- 모델 선택 기준은 날짜 균형 Brier이며, 별도 확률 보정 구간과 이후 평가 구간을 분리합니다.
- 반환하는 수익률 점 추정은 조건부 중앙값 대용치입니다. 경험적 오차 범위는 기대 수익이나 보장된 신뢰구간이 아닙니다.
- 종목명/코드 조회와 시각 검사를 통과한 원본 미래 예측 기록을 추가했습니다. 자동매매는 없습니다.

## 실제 학습 결과

학습은 616,595행·744일, 확률 보정은 64,704행·77일입니다. 두 구간의 정답은 2026-06-30까지 확인된 값만 사용합니다. 선택된 분류기는 Extra Trees이며, 반환하는 모델 파일에는 미래 평가 결과를 넣지 않습니다. 학습·보정 데이터 식별자와 구현 해시를 별도로 기록합니다.

| 7~9월 역사 개발 평가 | 동일 시점 부스팅 대조군 | 선택 모델 |
|---|---:|---:|
| 평가 행 / 신호일 | 52,002 / 62 | 52,002 / 62 |
| 전체 AUC | 0.5493 | 0.5533 |
| 날짜별 평균 AUC | 0.5340 | 0.5368 |
| 날짜 균형 Brier, 낮을수록 양호 | 0.249874 | 0.249627 |
| 고정 정책 충족 행 / 날짜 | 0 / 0 | 11 / 8 |

선택 모델에서 대조군을 뺀 Brier 차이는 -0.000247, 5거래일 블록 재표본 구간은 [-0.000978, +0.000289]입니다. 0을 포함하므로 확실한 개선이라고 말할 수 없습니다. 고정 정책의 모든 날짜 포함 비용 차감 5거래일 수익 대용치는 +1.739%이지만 구간 하한은 -0.037%입니다. 겹치는 기간의 종가 기반 연구 대용치이며 실제 매매·복리 수익률이 아닙니다.

선택 모델 정책 11건의 날짜 균형 성공률은 68.75%입니다. 표본이 매우 작고 날짜도 8일뿐이므로 모델 신뢰도가 68.75%가 됐다고 해석하지 않습니다. 10월 진단 구간도 7일뿐이며 선택 모델 AUC 0.5313, 정책 해당 1건은 실패입니다. 이 결과로 기준을 낮추거나 후보를 다시 고르지 않았습니다.

## 범위와 제약

경험적 수익 범위의 7~9월 포함률은 90.85%지만 평균 폭이 34.03%p입니다. 이는 상승 적중률도 검증된 신뢰도도 아닙니다. 시점별 시장 변화와 종목/날짜 의존성 때문에 향후 포함률 보장이 없습니다.

이미 본 역사 구간의 개발 평가이므로 독립적인 최종 검증으로 세지 않습니다. 현재 종목군과 사후 수정주가라는 한계도 남아 있습니다. 운영 추천 기준 미달로 항상 ABSTAIN이며 공개 기본 모델·추천 문턱은 바꾸지 않았습니다.
