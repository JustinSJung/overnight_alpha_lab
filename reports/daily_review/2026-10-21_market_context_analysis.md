# 시장 상황 특징과 날짜 균형 학습 비교 결과

## 결론

네 가지 모델을 실제로 학습했지만, 이번 설정에서는 신뢰할 만한 성능 개선을 확인하지 못했습니다. 운영 모델·추천 기준·공개 대시보드를 바꾸지 않았으며 모든 실험 모델은 연구용이고 추천 보류입니다. 시장 특징을 추가한 모델을 새 운영 모델로 채택하지 않습니다.

## 비교 조건

- 현재 후보군 901종목의 완료된 KIS 수정 일봉을 사용했습니다. 후보 생성 로직이나 후보군을 줄이지 않았습니다.
- 네 모델은 동일한 685,620행을 공유합니다. 시장 특징 부족으로 제외된 추가 행은 0개입니다.
- 시간 경계를 고정하고 정답이 다음 구간에 걸치는 행을 제거한 뒤 학습 398,764행, 확률 보정 137,002행, 개발용 과거 테스트 141,304행을 사용했습니다.
- 테스트는 166개 신호일입니다. 이미 살펴본 날짜이므로 새로운 독립 최종 테스트라고 주장하지 않습니다.
- 목표는 5거래일 종가 수익률이 비용 가정 0.3%를 초과하는지입니다. 추천 확률 기준 60%와 수익률 조건은 바꾸지 않았습니다.
- 분류기 종류는 학습 구간 안의 시간순 교차 검증으로만 선택했습니다. 테스트 결과로 새 특징이나 기준을 다시 조정하지 않았습니다.
- 시장 입력은 같은 날 거래가 있는 관측 후보군의 수익률·상승 비율·이동평균 상회 비율·변동성·거래량 등입니다. 실제 KOSPI/KOSDAQ 지수나 당시 시점의 완전한 전시장을 뜻하지 않습니다.

## 실제 결과

| 모델 | 전체 AUC | 날짜별 동일 비중 Brier | 조건 통과 표본 | 선정 날짜 평균 성공률 |
|---|---:|---:|---:|---:|
| 기존 가격 입력 | 0.515569 | 0.244244 | 1,081 | 45.37% |
| 가격 입력 + 날짜 균형 | 0.515824 | 0.244220 | 1,044 | 47.25% |
| 시장 특징 추가 | 0.511819 | 0.244219 | 0 | 해당 없음 |
| 시장 특징 + 날짜 균형 | 0.512074 | 0.244243 | 0 | 해당 없음 |

Brier는 작을수록 좋습니다. 같은 과거 확률을 사용하는 날짜 균형 기준선은 0.243851로, 네 모델 모두 이 기준선을 넘지 못했습니다. 조건 통과 표본은 과거 정책 분석용이며 실제 추천 승인 건수가 아닙니다. 마지막 성공률은 선정한 날짜들만의 평균이고 모델마다 선정 집합이 다릅니다.

## 날짜 집중과 불확실성

기존 모델은 학습 날짜당 표본이 최소 778개, 최대 849개, 중앙값 817개로 이미 비슷했습니다. 날짜 균형 가중치도 0.9585~1.0460 범위여서 표본 수 차이를 보정하는 효과는 작았습니다. 이 방식만으로 특정 시장 날짜에 후보가 몰리는 현상을 해결하지는 못했습니다.

테스트 날짜별 평균 확률 오차 차이를 짝지어 비교했습니다. 관측된 신호일 166개에서 길이 5의 원형 블록을 5,000회 재표본 추출했고 난수 시드는 42입니다. 값은 기존 모델 대비 Brier 차이이며 음수가 개선입니다.

| 모델 | 평균 차이 | 95% 블록 재표본 구간 |
|---|---:|---|
| 가격 + 날짜 균형 | -0.00002398 | [-0.00007601, +0.00002488] |
| 시장 특징 추가 | -0.00002521 | [-0.00158366, +0.00155021] |
| 시장 + 날짜 균형 | -0.00000121 | [-0.00165949, +0.00178160] |

모두 0을 포함합니다. 이 개발 데이터의 근사 구간만으로 개선이 입증됐다고 해석하지 않습니다. 미래 성과 보장이나 검증을 대신하지 않습니다.

후보를 선정하지 않은 날짜를 노출 0으로 포함한 166개 신호일의 평균 5거래일 비용 차감 수익률 대용치는 기존 모델 -0.2778%, 날짜 균형 모델 -0.0976%입니다. 연속 신호일 블록 기준 95% 하한은 각각 -1.8754%, -1.4966%입니다. 시장 모델 두 개는 선정이 없어 0이며, 이것을 좋은 성과나 실패한 예측으로 계산하지 않았습니다. 실제 일별 포트폴리오 수익률이나 체결 가능한 수익률이 아닙니다.

## 확률이 높아지지 않은 이유

시장 특징 모델은 학습 구간 안의 교차 검증에서도 기존 가격 모델보다 확률 손실이 컸습니다. 별도 보정 구간의 sigmoid 기울기는 기존 약 0.77에서 시장 모델 약 0.19로 작아졌습니다. 시장+날짜 모델의 테스트 확률 범위는 약 40.8~56.5%여서 60% 조건에 도달하지 않았습니다. 이 조건을 낮추거나 0건을 성공률 0%로 표시하지 않았습니다.

데이터 양이나 재학습 횟수를 늘린다는 사실 자체가 예측력 향상의 증거는 아닙니다. 이번 특징 조합은 채택하지 않고 부정적인 결과도 보존합니다. 후속 실험은 이번 과거 구간을 개발용으로 취급하고, 모델을 고정한 뒤 여러 날짜에 걸쳐 기록하는 미래 예측으로 별도 검증해야 합니다.
