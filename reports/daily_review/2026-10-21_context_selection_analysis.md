# 시장 정보 추가 학습 결과

## 구현

기존 OHLCV 입력 19개와 시장 대용 지표를 포함한 29개 입력을 비교했습니다. 시장 대용 지표는 관측 종목군의 완료 일봉으로 계산한 동일 날짜의 흐름·거래량·상승 비율·분산 및 종목 상대 강도입니다. KOSPI/KOSDAQ 지수나 실제 매매 가능한 수익률이 아닙니다.

각 입력에서 선형, 얕은/중간 부스팅, Extra Trees, 고정 평균 앙상블을 학습했습니다. 입력과 모델 종류를 선택하는 기준은 학습 구간 내부의 세 차례 순차 검증 Brier입니다. 보정 구간이나 이후 평가 결과는 선택에 쓰지 않습니다. 세 검증 모두 학습 정답 확인일이 검증 시작일보다 앞서도록 제거했습니다.

학습 616,595행·744일, 별도 확률 보정 64,704행·77일이며 두 비교군은 동일 행을 사용했습니다. 두 입력의 공통 결측 조건 때문에 추가 제외된 행은 0건입니다. 전체 901종목 후보군을 축소하지 않았습니다.

## 결과

학습 내부 선택은 **19개 입력의 Extra Trees**였습니다. 29개 입력군에서는 선형 모델이 가장 나았지만, 해당 검증 Brier는 0.246144로 19개 Extra Trees의 0.243384보다 나빴습니다. 낮을수록 좋은 지표입니다.

| 7~9월 과거 개발 평가 | 기존 입력 19개 | 시장 정보 포함 29개 |
|---|---:|---:|
| 평가 행 / 날짜 | 52,002 / 62 | 52,002 / 62 |
| 전체 AUC | 0.5533 | 0.5364 |
| 날짜별 평균 AUC | 0.5368 | 0.5171 |
| 날짜 균형 Brier | 0.249627 | 0.252745 |
| 고정 정책 해당 건 / 날짜 | 11 / 8 | 63 / 4 |

29개 모델에서 19개 모델을 뺀 Brier 차이는 +0.003118, 5거래일 블록 구간은 [-0.009794, +0.012761]입니다. 확실한 개선을 확인하지 못했고 점 추정은 오히려 나빴습니다. 두 모델의 고정 정책 수익 대용치 구간 하한도 0보다 낮았습니다.

10월의 짧은 진단 구간은 5,853행·7일입니다. 29개 모델의 전체 AUC 0.5842와 Brier 0.184580은 19개보다 좋았지만, 날짜별 AUC는 0.4485였고 정책 해당 건은 0입니다. 짧은 구간의 전체 지표만 골라 성능 향상이라고 주장하지 않습니다.

## 보존 및 한계

입력을 늘린 모델로 무조건 교체하지 않고 학습 내부 선택을 유지했습니다. 기존 19개 모델의 종목 조회 결과도 유지됐고, 동일 평가 행의 확률·수익률 예측은 부동소수점 수치 정밀도 범위에서 재현됐습니다. 코드 해시·학습 데이터 식별자를 남겼으며, 기존 모델 포인터·공개 예측·추천 문턱·원본 미래 기록은 바꾸지 않았습니다.

공통 조회·미래 원장 도구는 두 입력 스키마를 지원합니다. 원본은 적시 기록만 가능하고 덮어쓰지 않습니다. 모델 종류가 다르거나 다시 학습한 파일의 평가 실적을 합쳐 신뢰도를 부풀리지 않습니다.

이 평가는 반복해서 본 과거 개발 구간입니다. 독립적인 미래 검증이나 고신뢰도 추천 모델 완성으로 해석하지 않습니다. 현재 종목군·사후 수정주가 한계도 남습니다. 항상 추천 보류이며 운영 교체·스케줄 등록·배포는 하지 않았습니다.
