# 상대 성과 학습 실험 결과

## 이번에 확인한 것

기존 절대 수익 예측을 바꾸지 않고, 같은 날 입력 가능한 후보들의 평균보다 5거래일 뒤 더 나은 종목을 구분하는 모델을 별도로 학습했습니다. 상대 확률은 매수 성공 확률이나 대시보드 신뢰도 점수가 아닙니다. 후보군 평균이 -10%라면 -5% 수익도 상대 목표에서는 성공일 수 있습니다.

현재 후보군 901종목의 저장된 완료 일봉을 재사용했습니다. 입력 조건은 미래 결과를 보지 않고 정했습니다. 평가 기간에는 총 878종목이 한 번 이상 입력 조건을 충족했고, 날짜별로 794~866종목이 해당했습니다. 후보 생성 로직이나 넓은 후보 풀은 줄이지 않았습니다. 166개 신호일·141,304행 모두 결과가 확인되어 누락으로 제외한 평가 날짜는 없습니다.

## 고정한 비교 조건

- 기존 가격 특징 9개, 기존 Gradient Boosting 설정, 날짜별 동일 학습 비중입니다.
- 상대 목표 모델과 절대 목표 대조군은 학습·보정 날짜와 모델 설정이 같습니다.
- 학습 398,764행, 별도 확률 보정 137,002행, 과거 평가 141,304행입니다.
- 학습 정답은 보정 시작일 전까지, 보정 정답은 2025-10-17까지 알려진 것만 사용했습니다. 상대 정답은 같은 날 후보 전원의 결과가 알려진 시점부터 사용할 수 있습니다.
- 평가 신호일은 2025-10-20~2026-06-23, 마지막 정답 확인일은 2026-06-30입니다.
- 주 평가는 매일 상위 20개, 보조 평가는 상위 10개입니다. 확률 문턱이나 모델 설정을 결과에 맞춰 조정하지 않았습니다.
- 비교 대상은 전체 후보 동일 비중, 최근 20거래일 모멘텀, 고정된 100회 무작위 선택 평균, 같은 조건의 절대 목표 모델입니다.

## 불확실성과 확률 진단

상대 모델 상위 20개와 각 대조군의 날짜별 수익 차이를 5개 신호일 블록으로 5,000회 재표본 추출했습니다. 네 비교에 대해 Bonferroni 보정을 적용한 구간은 전부 0을 포함했습니다.

상대 목표 모델의 날짜별 평균 AUC는 0.5190입니다. 상대 목표에 대한 Brier는 0.241868로 과거 상수 확률 0.242015보다 조금 낮지만, 이 작은 오차 개선은 상위 종목 선별의 우위를 입증하지 못했습니다. 절대 목표 모델의 AUC는 0.5212입니다. 두 모델은 정답 정의가 다르므로 Brier 숫자 자체를 서로 비교해 신뢰도 향상이라고 주장할 수 없습니다.
