# 자연모방 모델: 실제 구현과 검증 결과

## 가설을 코드로 바꾼 범위

자연의 원리를 가져오면 주가 예측이 크게 좋아질 수 있다는 아이디어를 두 개의 구체적인 연구 가설로 나눴다. 알려진 생체모방 구현을 기반으로 이 프로젝트에 새로운 결합을 시험했으며, 새로운 보편 알고리즘을 발견했다거나 자연의 법칙으로 수익을 보장한다는 뜻은 아니다.

1. **시간 적응 신경회로**: 하루 요약값만 보던 모델과 달리 20거래일 동안의 19개 입력 변화를 기억한다. 소형 생물 신경회로에서 영감을 받은 NCP/CfC와 일반 GRU, dense CfC, 마지막 하루 MLP를 비교했다.
2. **종목 간 정보 교환**: 개별 모델이 자기 이력만 보지 않고 학습 구간에서 연관된 다른 종목의 관측 정보를 받는다. 흥분/억제와 유사하게 부호가 있는 연결을 사용했다. 실제 연결과 같은 연결 수·가중치의 무작위 연결, 같은 정보를 받는 일반 GRU를 비교했다.

벌집의 모양을 특징 행렬로 바꾸는 방식이 아니라, 시간적 기억과 분산 정보 교환이 추가 예측 정보를 만드는지 확인하는 방식이다. 실제 벌·개미의 군집 행동이나 자율신경계를 충실하게 시뮬레이션했다고 주장하지 않는다.

## 공정한 비교 조건

- 정답: 다음 관측 거래일 시가부터 다섯 번째 관측 거래일 종가까지의 수익률이 가정 비용 0.3%를 넘는지.
- 각 평가 기간에 모든 모델의 입력 후보, 정답, 비용, 날짜 경계, 순위와 고정 추천 문턱을 동일하게 사용했다.
- 동일한 입력 전용 표본 추출 규칙으로 46,071행·725개 신호일을 학습하고 별도 31,902행·38개 신호일로 확률을 보정했다. 학습 계산량을 제한한 탐색용 예산이며 전체 예측 후보군을 줄이지 않았다.
- 모든 신경망은 고정 8회 학습하고 난수 시드 17/42의 결과를 똑같이 평균했다. 평가 결과를 보고 최상의 시드·모델·학습 횟수·문턱을 선택하지 않았다.
- 그래프는 2026-02-20까지의 관측 입력으로만 만들었다. 901개 종목 중 816개에 연결이 있고, 총 3,086개다. 각 지연 관계는 학습 구간 두 절반에서 같은 부호이고 절댓값 0.08 이상이어야 했다. 이는 연관성이지 인과성의 증거가 아니다.
- 결측 이력이나 정보 전달의 부재를 명시적으로 처리했다. 평가 결과가 없는 상위 종목을 빼고 다른 종목으로 다시 순위를 매기지 않았다.

## 7~9월 주 개발 구간 실제 성적

주 평가 구간의 입력 후보는 모델별 동일한 52,017건이다. 이 기간은 이미 이전 실험에서 살펴본 **과거 개발 자료**이며 새로운 독립 시험은 아니다. 아래 상위 20 성공률은 평가 가능한 결과의 날짜별 평균이다. 미확인 결과가 있으므로 완전한 추천 전략 성과가 아니다.

| 모델 | 날짜 균등 Brier, 낮을수록 좋음 | 날짜별 평균 AUC | 상위 20 조건부 성공률 |
|---|---:|---:|---:|
| 하루 요약 MLP | 0.247737 | 0.530654 | 44.76% |
| 일반 GRU | 0.248110 | 0.530177 | 44.22% |
| Dense CfC | 0.248217 | 0.527321 | 43.84% |
| NCP CfC | 0.247495 | 0.533376 | 43.67% |
| 동일 표본 Extra Trees | 0.249242 | 0.529291 | 45.77% |
| 실제 연결 정보를 받는 NCP | 0.248899 | 0.524590 | 44.79% |
| 무작위 연결 정보를 받는 NCP | 0.248995 | 0.519137 | 46.17% |
| 실제 연결 정보를 받는 GRU | 0.248673 | 0.523173 | 45.29% |

NCP의 Brier는 일부 대조군보다 수치상 작았지만, 미리 정한 네 비교 모두 날짜 묶음 재표집의 다중 비교 보정 구간이 0을 포함했다. 상위 추천군 성과도 좋아지지 않았다. 정보 교환 모델의 실제 연결은 무작위 연결보다 확실히 우수하지 않았으며, 일반 GRU 전달도 이기지 못했다.

기존의 **전체 데이터** Extra Trees도 같은 52,017개 후보에서 별도 재평가했다. 학습 614,781행·744일, 같은 확률 보정 기간의 모델이다. Brier 0.247410, 날짜별 평균 AUC 0.536864, 상위 20 조건부 일별 성공률 45.88%였다. 학습 예산이 다르므로 구조 효과의 엄밀한 대조군은 아니지만, 이번 새 모델이 기존 시스템보다 좋다고 주장할 근거도 없다. 이 검사는 주 비교를 바꾼 것이 아닌 추가 보수적 점검이다.

10월 짧은 구간에서도 실제 연결 NCP의 상위 20 조건부 성공률은 약 24.98%로 낮았다. 유리한 기간이나 무작위 연결의 높은 특정 문턱 성적만 골라 운영 모델로 승격하지 않았다.

## 현재 판단

**두 가설은 구현·학습·비교까지 했지만 고신뢰도 예측력은 입증하지 못했다.** 이것은 모든 자연모방 방법이 불가능하다는 결론이 아니라 이번 입력·학습 예산·고정 구조에서 성공 증거가 없다는 뜻이다. 학습 손실 감소, 여러 모델의 동의, 연결 수 증가를 미래 적중률이나 검증된 신뢰도로 바꾸어 표시하지 않는다.

반복해서 같은 과거 기간을 살펴본 개발 실험이라는 한계가 크다. 실제 새로운 예측은 마감 후·개장 전에 각 대조군 확률과 함께 별도로 봉인하고, 이후 가격이 도착하면 그 원본으로만 평가한다. 추천은 보류하며 기존 운영 모델·원본·공개 신뢰도 지표를 대체하지 않는다.
