# AI 수식 탐색과 잔차 기반 후속 실험

## 구현한 것과 아직 달성하지 못한 것

유전 프로그래밍으로 신호 수식을 생성하고 학습 내부의 뒤쪽 구간에서 생존 검사를 수행하는 AI 탐색 엔진을 구현·실행했습니다. 단순히 사람이 정한 모델 목록을 비교하는 것과 달리, 고정된 산술 연산을 조합한 프로그램 자체를 탐색합니다. [gplearn 공식 API](https://gplearn.readthedocs.io/en/stable/reference.html)를 사용했습니다.

**검증된 고신뢰도 추천 모델은 아직 확보하지 못했습니다.** 생성된 후보를 새로운 과학적 알고리즘 발명이나 시장 예측의 패러다임 전환으로 표현하지 않습니다. 자동 수식 탐색 또한 알려진 AI 기법입니다.

## 첫 실험: 단순 선형 조합의 한계 확인

최대 128개체·6세대로 수식을 진화시켰습니다. 원래 입력의 상대 순위 목표와 관련된 후보 3개가 뒤쪽 학습 구간 검사를 통과했지만, 모두 기존 순위 입력의 합이었습니다. 이런 항을 선형 모델에 더하는 것은 새로운 함수 표현력을 주지 않습니다.

47일 과거 외부 개발 평가에서 수식 추가 모델과 같은 선형 대조군의 Top20 목록도 같았고 확률 오차 차이도 극히 작았습니다. 첫 실험 모델·규약·결과를 보존했고 고신뢰도 발견으로 발표하지 않았습니다.

## 후속 설계: 모델이 아직 설명하지 못한 잔차에서 수식 탐색

1. 학습 앞부분에서 표준화/Ridge 기준 모델의 순차 검증 예측을 세 번 만듭니다. 각 예측의 학습 정답은 검증 시작 전에 확인된 값만 사용합니다.
2. 그 표본 외 예측의 잔차를 대상으로 유전 프로그래밍을 수행합니다. 계산 표본은 348일·22,272행이며, 날짜별 고정 난수로 최대 64개를 골랐습니다. 전체 학습·추론 후보군은 줄이지 않았습니다.
3. 상수·단순 입력 복사·복잡한 수식뿐 아니라 기존 38개 입력의 선형 조합으로 재현되는 수식을 제외합니다. 발견 구간의 선형 회귀 잔차 비율이 최소 5%여야 합니다.
4. 뒤쪽 학습 275일·235,606행을 세 구간으로 나눠 잔차 신호가 유지되는지 검사합니다. 이 단계도 외부 평가가 아니라 학습 내부 선택입니다.
5. 최종 학습 616,595행·744일, 확률 보정 32,332행·38일, 정책 선택 28,360행·34일을 별도 날짜로 분리합니다. 최종 목표는 상대 순위 적중이 아니라 실제 5거래일 수익 +0.3% 초과입니다.

## 실제 생성·생존 수식 2개

아래 변수는 같은 날짜에 입력이 유효한 전체 후보군에서 계산한 백분위 순위입니다. 미래 결과를 보기 전에 순위 모집단을 고정했습니다.

- R: 과거 20일 일중 가격 범위 평균의 순위
- G: 과거 20일 갭 변동성 순위
- M: 5일 이동평균/20일 이동평균 상대 위치 순위
- T: 5일/20일 거래량 추세 순위
- V: 과거 20일 수익 변동성 순위

```text
g1 = -(min(G, M - max(T, M)) + R + M)
g2 = -(R + min(M, G, V))
```

방향 부호는 발견 구간만으로 정했습니다. 기존 전체 입력의 선형 조합으로 설명되지 않는 잔차 비율은 각각 20.84%, 22.41%였습니다. 이는 새로운 정보의 양이나 성공률을 뜻하지 않고, 단순 선형 복사인지 확인하는 수치입니다.

세 후속 학습 구간의 날짜별 잔차 순위 상관은 g1이 0.0362/0.0099/0.0038, g2가 0.0392/0.0006/0.0081이었습니다. 사전에 정한 생존 조건은 통과했지만 뒤 구간에서 신호가 약했습니다. 생존 검사는 탐색용 기준이지 미래 성능 보장이 아닙니다.

## 동일 날짜의 외부 과거 개발 평가

7~9월 대상 62일 중 전체 후보의 결과가 확인된 47일·39,463행을 비교했습니다. 불완전한 15일은 날짜 전체를 제외했습니다. 10월 진단 7일은 완전 날짜 0일로 평가 불가입니다. 전체 날짜 제외도 평가 편향의 한계이며, 결과 없는 종목만 지우고 순위를 다시 매기지는 않았습니다.

| 지표 | 순위 입력 선형 대조군 | 잔차 수식 추가 모델 | 기존 구조 Extra Trees 대조군 |
|---|---:|---:|---:|
| 날짜 균형 Brier, 낮을수록 좋음 | 0.256353 | 0.256149 | 0.249859 |
| 날짜별 평균 AUC | 0.5115 | 0.5097 | 0.5376 |
| 진단용 Top20 성공률 | 40.53% | 39.68% | 47.34% |
| 진단용 Top20 5일 비용 차감 수익 대용치 | +0.325% | +0.782% | +1.343% |

수식 추가 모델의 Brier는 선형 대조군보다 0.000203 낮았지만 블록 구간 [-0.000477, +0.000101]이 0을 포함했습니다. Extra Trees보다 오차가 컸으며 그 차이 구간은 [+0.003887, +0.008861]이었습니다. 단순한 모델보다 복잡한 생성 수식이 항상 낫다는 가설은 지지되지 않았습니다.

Top20은 매일 강제로 20개를 고른 진단이지 활성화된 추천이 아닙니다. 선형 대조군·Extra Trees·모멘텀·무작위 대비 수익 비교는 확정적 우위를 입증하지 못했습니다. 겹치는 종가 대 종가의 연구 수익 대용치이며 실제 체결·슬리피지·복리 수익을 재현하지 않습니다. 후보군 대비 성과를 실제 주가지수 대비 수익으로 해석하지 않습니다.

## 추천 정책: 전부 탈락

정책 구간에서만 고정된 확률 문턱 55/60/65/70%와 일별 최대 5개 정책을 비교했습니다. 표본 수·관측 성공률·블록 하한·수익 하한 조건을 모두 요구했고 다중 비교도 보정했습니다.

- 55% 문턱: 170건·34일, 날짜 균형 성공률 25.88%
- 60% 문턱: 158건·34일, 날짜 균형 성공률 22.75%
- 65% 문턱: 88건·24일, 날짜 균형 성공률 36.11%
- 70% 문턱: 12건·9일, 표본 부족

선택 정책은 `None`입니다. 예측 확률 65%가 검증된 적중률 65%를 뜻하지 않는다는 점이 다시 확인됐습니다. 운영 추천은 활성화하지 않았으며 보류를 성공으로 세지 않았습니다.

## 구현 검증과 보존

격리된 `.venv-discovery`에서 전체 101개 테스트가 통과했습니다. 기존 `.venv-ml`에서도 101개 중 새 환경 전용 통합 테스트 1개를 제외한 나머지가 통과했습니다. 잔차의 시점 분리, 선형 중복 검사, 종목 조회, 원본 미래 기록 불변성, 소급 기록 차단, 5거래일 뒤 채점을 검사했습니다.

기존 scikit-learn 1.6.1 환경은 유지하고 새 연구 환경만 1.8.0/gplearn 0.4.3으로 고정했습니다. 기존 운영 모델 포인터·공개 예측·원본 미래 원장·후보군은 유지했습니다. 새 모델과 환경은 Git에서 제외했고 자격증명은 출력하지 않았습니다. 예약 실행·원격 배포·매매 기능은 추가하지 않았습니다.

두 번의 수식 탐색은 반복해서 본 역사 자료를 사용한 개발 실험입니다. 새로운 독립 검증 자료가 생긴 것으로 세지 않습니다. 같은 외부 평가 구간의 점수가 오를 때까지 탐색 조건을 계속 바꾸는 것은 고신뢰도 검증이 아닙니다. 향후에는 새 정보의 시점 정확성과 사전 기록한 실제 미래 결과를 확보해야 하며, 현재 실패만으로 모든 가격 기반 AI가 불가능하다고 단정하지도 않습니다.
