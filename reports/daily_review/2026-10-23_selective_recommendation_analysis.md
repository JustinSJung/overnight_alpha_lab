# 추천 판단 모델: 구현과 실제 검증

## 현재 결론

기존 예측을 받아 추천 가능성을 따로 학습하는 연구 모델을 구현하고 실제로 학습했다. **고신뢰도 추천 모델로 승인할 근거는 아직 부족하다.** 단순히 새 모델이 생겼다거나 학습이 끝났다는 사실을 예측력 향상으로 표현하지 않는다.

## 실제로 학습한 자료

- 입력은 KIS 901종목의 10월 22일까지 완료된 기존 가격 이력이다. 운영 모델과 저장된 미래 예측 원본은 변경하지 않았다.
- 2025년 7월부터 2026년 10월까지 16개월의 기본 예측기를 각각 그 달 시작 이전 자료로 학습했다. 각 예측기는 과거 504개 신호일 학습과 별도 60일 확률 보정을 사용했다.
- 272,104개 시간 외 예측 기록을 만들었다. 같은 모델의 학습 자료에 대한 예측을 두 번째 모델의 훈련 정답으로 사용하지 않았다. 이것은 당시 실제 발행한 원본이 아니라 엄격한 시간 경계를 적용한 과거 재현이다.
- 추천 판단 모델은 최근 126개 신호일을 학습하고 별도 30일로 확률을 보정했다. 5~10월의 평가용 판단 모델도 각각 월 시작 전에 학습한 것으로 재현했다.
- 현재 조회용 판단 모델의 훈련 행은 105,163개, 보정 행은 24,759개다. 마지막 정답 확인일은 10월 22일이다. 이 보정 자료를 독립적인 시험 성적으로 사용하지 않았다.
- 예측 확률, 같은 포리스트 내부의 분산, 학습 분포와 입력의 거리, 당시 관측 가능한 종목·시장 정보와 그날 이전에 확인된 오차를 사용했다. 미확인 결과 비율도 남겼다. 포리스트 내부 분산은 독립적인 여러 모델의 동의나 검증된 신뢰도가 아니다.
- 정답은 기존 BUY 기준과 동일하다. 다음 관측 거래일 시가부터 다섯 번째 관측 거래일 종가까지의 상승이 가정 비용 0.3%를 넘는지 평가했다. 회피형 후보의 성공률을 섞지 않았다.

## 동일한 일별 5개 선택의 결과

아래 성공률은 평가 가능한 선택 종목의 **날짜별 평균**이다. 미확인 선택을 다른 종목으로 바꾸지 않았다. 서로 다른 미확인 결과가 있기 때문에 표의 차이만을 완전한 추천 전략 개선으로 해석할 수 없다.

| 기간 | 기존 월별 예측 | 확률 보정만 한 대조군 | 추천 판단 학습 |
|---|---:|---:|---:|
| 5~6월 | 34.49% | 27.69% | 32.69% |
| 7~9월 | 48.58% | 39.44% | 51.85% |
| 10월 1~15일 | 28.89% | 28.89% | 31.11% |

7~9월에는 전체 입력 후보 52,017건, 62개 신호일을 세 방식 모두 동일하게 평가했다. 각 방식의 선택은 310건이며, 결과 확인 수는 기존 288건, 보정 대조군 297건, 판단 학습 306건이다. 미확인은 각각 22건, 13건, 4건이다.

양쪽 선택 결과가 모두 완전한 45개 날짜에서 판단 학습의 기존 방식 대비 차이는 +2.22%p다. 두 주 비교에 대한 다중 비교 보정 날짜 블록 구간은 **-8.10~+12.31%p**로 0을 포함했다. 확률 보정 대조군보다 나은 부분적 신호는 있었지만, 기존 모델보다 낫다는 근거를 대신하지 못한다. 미확인 날짜가 있으므로 완전한 기간의 성과 하한은 제공하지 않았다.

확률 오차 Brier는 7~9월에 기존 0.260828, 보정 대조군 0.267082, 판단 학습 0.276231이었다. **작을수록 좋은 지표이므로 판단 모델은 오히려 나빴다.** 10월의 조건부 평균 순수익률 대용값도 기존 약 -1.30%, 판단 모델 약 -4.04%로, 적중률이 조금 높다는 사실만으로 손익 개선을 주장할 수 없다.

별도의 고정 60% 문턱 정책은 7~9월과 10월 구간에 선택이 0건이었다. 문턱을 사후에 낮춰 추천이 나오도록 만들지 않았다. 상위 5개 표는 연구용 순위 비교이며 매일 5종목을 매수하라는 추천이 아니다.

## 현재 조회와 원본 발행 상태

- 종목명 `삼성전자`와 종목코드 `005930`으로 새 연구 모델 조회를 실제 확인했다.
- 현재 입력 조건을 충족한 834종목을 모두 예측한다. 최고 판단 확률은 약 37.0%였으며 문턱 선택과 승인된 추천은 모두 0건이었다. 이 확률은 연구 추정치이지 실제 미래 적중률이 아니다.
- 최신 판단 모델의 확률 보정 기울기는 -0.551이었다. 보정 구간에서 원시 점수와 정답의 관계가 안정적으로 양수가 아니었다는 점검 대상이며, 사후에 부호를 강제로 바꾸거나 고신뢰도라고 표시하지 않았다.
- 10월 23일 장중에 22일 신호를 새 원본으로 발행하는 실행은 시간 검증에서 차단됐다. 실제 원본 CSV나 명세 파일은 생성되지 않았다. 소급 예측을 미래 검증 증거로 만들지 않았다.
- 새 원본을 기록하려면 오늘 또는 이후의 완료 일봉으로 마감 후부터 다음 개장 1분 전까지 발행해야 한다. 이번 실행은 예약 작업이나 자동 주문을 설치하지 않았다.
- 기존 21일 일반 예측과 22일 두 자연모방 실험 원본의 SHA-256이 이전 기록과 같음을 확인했다.

## 검증

- 신경망 환경 전체 테스트 145개 실행: 144개 통과, 선택 의존성 1개 건너뜀.
- 기존 ML 환경 전체 테스트 145개 실행: 139개 통과, 선택 의존성 6개 건너뜀.
- 추천 판단 모델 테스트 7개와 진단 화면 테스트 2개를 추가했다. 미래 정답 배제, 정답을 바꿔도 선택 불변, 동일 일별 선택 수, 미확인 종목 보존, 원본 불변·해시, 모델 파일 변조, 개장 이후 발행 차단을 확인했다.
- 수정 Python 구문 검사, 셸 구문 검사, `git diff --check` 통과.
- 대시보드와 내부 진단 HTML 재생성 완료. 기존 CSV의 혼합 자료형 경고는 남았지만 생성은 성공했다.
- 실제 Chrome 1440/390/320px에서 종목명·코드 조회, 추천 보류, 오래된 가격 경고, 공개/진단 분리와 표 내부 가로 스크롤을 검증했다. JavaScript 오류는 없었다.
- 새 커밋·GitHub 배포·운영 추천 활성화는 하지 않았다. 학습 파일과 원본 동반 명세는 Git 제외로 보존했다.

이번 결과는 두 번째 판단 모델의 구현 가능성과 작동을 확인한 것이지 사용자의 고신뢰도 목표 달성을 의미하지 않는다. 반복해서 살펴본 과거 기간의 수치 향상만으로 신뢰도를 올리거나 추천을 승인하지 않는다.
