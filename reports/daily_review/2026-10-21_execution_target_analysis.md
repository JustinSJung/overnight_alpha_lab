# 신뢰도 정체 원인 점검과 학습 기준 수정

## 완료된 일과 완료되지 않은 목표

고신뢰도 추천 모델은 아직 완성되지 않았다. 실험 실행 완료를 사용자의 목표 달성으로 표현하면 안 된다. 성공률이나 표시 점수를 높이려고 정답, 후보 수, 승인 기준을 유리하게 바꾸지 않았다.

## 이번 확인 결과

- 901개 종목 원본 796,665행에서 날짜 중복, 비유한 OHLCV, 음수 거래량, 거래가 있는 날의 OHLC 모순은 0건이었다.
- 거래량 0인 행은 27,178개, 하루 종가 변화 절댓값 30.5% 초과는 26개였다. 거래정지·기업행사·특수 매매 등의 확인 대상이지 전부 수집 오류라는 뜻은 아니다.
- 기존 장 마감 입력으로 같은 종가부터 수익을 계산한 목표는 실제 다음 날 진입 목표가 아니다. 7~9월 기존 평가 행 중 진입 시가가 있는 51,874개에서 3,591개의 이진 정답이 달라졌다. 단순 가격 비교 단계의 수치이며 최종 엄격한 평가 코호트와 다르다.
- 과거 비교 모델은 2월까지 분류기를 학습하고 3~4월에 확률을 보정했다. 연구 모델 실행 횟수와 최신 정답을 반영한 재학습은 다른 일이다. 적응형 사례 모델의 역사 재현도 실제 사전 예측 성적은 아니다.

## 새 정답으로 대조한 실제 성적

동일 19개 입력, Extra Trees, 같은 학습/보정 행을 사용했다. 이전 종가 목표로 학습한 대조군과 다음 날 시가 목표로 학습한 모델 모두 **다음 시가 목표로** 채점했다. 미래 결과를 보기 전 후보 전체에 순위를 매겼다.

| 7~9월 개발 구간 | 종가 목표 학습 대조군 | 다음 시가 목표 학습 |
|---|---:|---:|
| 입력 후보 | 52,017 | 52,017 |
| 평가 가능 / 미확인 | 51,483 / 534 | 51,483 / 534 |
| 날짜 균등 확률 오차 Brier, 낮을수록 좋음 | 0.250763 | 0.247410 |
| 날짜별 평균 AUC | 0.535080 | 0.536864 |
| 고정 60% 문턱·일별 최대 5개 선택 | 310 | 298 |
| 선택 후 평가 가능 / 미확인 | 287 / 23 | 282 / 16 |
| 평가 가능한 선택의 성공률 | 47.04% | 49.65% |

확률 오차 차이의 5일 묶음 재표집 95% 구간은 [-0.007100, +0.001192]로 0을 포함한다. 이미 반복해 본 개발 기간이며 독립적인 개선 증거로 확정하지 않는다. 선택 결과 일부가 미확인이므로 전체 추천 정책의 수익을 확정하지 않는다. 10월 짧은 구간의 새 모델 선택 성공률도 18.75%로 낮았다. 좋은 기간만 골라 제시하지 않는다.

## 최근 자료의 실제 학습

별도 미래 검증 모델은 확정 정답을 반영해 재학습했다.

- 분류기: 2024-06-10~2026-07-06, 504개 신호일, 425,644개 학습 행. 마지막 정답 확인일 7월 13일.
- 확률 보정: 2026-07-14~2026-10-13, 60개 신호일, 49,685개 보정 행. 마지막 정답 확인일 10월 20일.
- 보정 자료는 독립적인 시험 자료로 재사용하지 않는다.
- 기존 모델·기본 대시보드·과거 원장을 보존하고 새 모델/정답 이름으로 실제 미래 예측을 분리한다.
- 원본 기록을 장 시작 후 소급 생성하거나 덮어쓰지 않는다. 새 모델도 추천은 보류한다.

현재의 한계는 단순히 학습을 한 번 더 실행하지 않았다는 것만이 아니다. 입력 정보의 예측력이 약하고 기간에 따라 확률 보정도 달라진다. 다음 날 진입 목표, 실제 최신 정답 학습, 수정 불가능한 미래 원장을 갖춘 뒤에야 실질적 개선 여부를 정직하게 판단할 수 있다. 미래 가격이 아직 오지 않은 예측의 성공률은 지금 만들어낼 수 없다.

KIS 요청의 수정주가 모드 0은 공식 예제와 일치한다. 모드가 뒤집혔다는 근거는 발견하지 않았다: [KIS 공식 기간별 시세 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_itemchartprice/inquire_daily_itemchartprice.py).
